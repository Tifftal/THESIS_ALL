# СИРОГС (Система измерений размеров объектов на гистологических снимках)

Автоматизированной системы для анализа гистологических изображений, основанной на нейросетевой модели CellPose-SAM. Система предназначена для точного измерения размеров клеточных структур, что актуально в условиях роста объёмов медицинских и биологических данных. Решение сочетает высокопроизводительную серверную часть на Go и Python с использованием gRPC для взаимодействия модулей, объектное хранилище MinIO, реляционную СУБД PostgreSQL и кэширование Redis для ускорения обработки. Клиентское приложение реализовано на React и Tauri, обеспечивая низкое потребление ресурсов и кроссплатформенность.
